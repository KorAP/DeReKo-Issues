# DeReKo – Korpusfehler melden

*English below. You are welcome to write your report in German or English.*

Sie haben im **Deutschen Referenzkorpus (DeReKo)** einen Fehler entdeckt?
Dann melden Sie ihn bitte hier, auch wenn Sie unsicher sind, ob es wirklich ein Fehler ist.
Jede Meldung hilft uns, das Korpus zu verbessern.

Sie können **auf Deutsch oder Englisch** schreiben. Vorkenntnisse in Git oder Programmierung brauchen Sie nicht.

## Was können Sie melden?

Zum Beispiel:

- falscher oder fehlender Text, abgeschnittene oder doppelte Passagen
- kaputte Zeichen, Umlaute oder Sonderzeichen (z. B. `Ã¤` statt `ä`)
- falsche Metadaten: Autor, Titel, Datum, Quelle, Textsorte, Ressort usw.
- falsche Annotationen: Wortart, Lemma, Morphologie, Satz- oder Tokengrenzen
- Texte, die nicht ins Korpus gehören, oder auffällige Lücken
- alles andere, was Ihnen bei der Arbeit mit DeReKo seltsam vorkommt

Probleme mit der **Suchoberfläche KorAP** selbst (Bedienung, Abfragesprache, Absturz) melden Sie bitte unter
<https://github.com/KorAP/Kalamar/issues>. Wenn Sie nicht sicher sind, wohin es gehört: einfach hier melden, wir leiten es weiter.

## So geht's

1. Melden Sie sich bei GitHub an. Ein [Konto](https://github.com/signup) ist kostenlos.
2. Klicken Sie oben auf **Issues** und dann auf **New issue**.
   Alternativ: In [KorAP](https://korap.ids-mannheim.de) im Menü **Korpusgrundlage → Korpusfehler**.
3. Beschreiben Sie kurz, was Ihnen aufgefallen ist, und klicken Sie auf **Create**.

Das war's! Wir melden uns im Issue, falls wir Rückfragen haben.

## Hilfreiche Angaben (soweit vorhanden)

Je genauer, desto schneller können wir den Fehler finden. Aber auch eine kurze Meldung ist willkommen.

- **Was** ist falsch, und was wäre richtig?
- **Wo**: die Textsigle (z. B. `WPD17/A00/00001`) oder der Link zum Treffer in KorAP
- **Wie gefunden**: Ihre Suchanfrage und das durchsuchte (virtuelle) Korpus
- ggf. ein Screenshot

## Bitte beachten

- Issues sind **öffentlich** sichtbar. Bitte keine persönlichen Daten angeben.
- Viele Texte in DeReKo sind urheberrechtlich geschützt. Bitte **keine längeren Textpassagen** einfügen,
  ein kurzer Ausschnitt rund um die Fundstelle oder die Sigle genügt.

Vielen Dank für Ihre Hilfe!

## English

Found an error in the **German Reference Corpus (DeReKo)**? Please report it here, in **German or English**, even if you are not sure it is really an error.
Open [Issues → New issue](../../issues/new) (a free GitHub account is required) or use **Corpus → Corpus issues** in [KorAP](https://korap.ids-mannheim.de).
Helpful details: what is wrong, the text sigle or KorAP match link, your query and corpus, and a screenshot if useful.
Issues are public: please do not include personal data or longer copyrighted text passages.
Problems with the KorAP search interface itself belong in <https://github.com/KorAP/Kalamar/issues>.
